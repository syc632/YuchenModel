- 传统的线性注意力:
	- $$\mathrm{Attention}(Q,K,V)=\frac{\phi(Q)\left(\phi(K)^{\top}V\right)}{\phi(Q)\phi(K)^{\top}\mathbf{1}}$$
	- $$o_i=\frac{\phi(q_i)^{\top}S}{\phi(q_i)^{\top}Z}$$
	- $$其中,S_t = S_{t-1} + KV^T$$
	- 问题:每来一个token,**就会把K和V的外积累加到同一个S**,在刚开始的时候,不同K的方向足够不同,Q 还可以找到读回来和自己相近的那部分信息,但是随着历史的关联越来越多,==多个关联会叠加到相同或相近的方向上:==
		- 新的信息会改变旧的信息在S中的表示
		- 用某个Query去读取的时候,读取到的是目标关联加上其他关联的“干扰”
		- 因为没用逐token的槽位(比如Softmax注意力),所以无法精确地把某一条旧记录单独地取出或删除
	- 因为线性注意力的主要优势就在于当Seq_len远大于D_model的时候,但是当Seq_len远大于d_model的时候会有以上三个问题,这导致线性注意力有非常大的局限性
	- $$S k_j=\sum_i v_i \left(k_i^\top k_j\right)=v_j + \underbrace{\sum_{i \ne j} \left(k_i^\top k_j\right) v_i}_{\text{检索错误}}$$
	- 上述的公式很好的展示了当我们用一个特定的查询键即k本身($q=k_j$)去查询$k_j$所对应的值$v_j$,我们会发现除了$v_j$还会有一些检索错误,这些错误是我们不想要的 **直觉上,如果我们想要让错误消失,就需要满足$k_i^Tk_j = 0$,换句话说,即$k_i$和$k_j$正交,即所有的键都需要彼此正交,但是问题随之而来,状态S只有d维,所以最多只有d个k是正交的**
	- 因此,传统的线性注意力与softmax注意力相比,表现不佳的原因主要在于==内存“过载”==,在这种机制下,状态只能单纯的增加,这导致k越加越多而==无法删除已有的信息==
- DeltaNet
	- DeltaNet将[[DeltaRule]]应用于线性注意力,它不再简单地累加kv外积,而是基于预测误差来更新状态
	- $$\begin{aligned}S_t&= S_{t-1}- \beta_t \left(S_{t-1} k_t - v_t\right) k_t^\top \\&= S_{t-1}- \beta_t S_{t-1} k_t k_t^\top+ \beta_t v_t k_t^\top\end{aligned}$$
	- $$k_t是输入数据,\beta充当学习率,v_t是目标,S_{t-1}k_t是根据当前状态的预测,也就是v_{t}^{old}$$
	- 另一种更加直观的方法去理解这个公式:我们可以把公式中的$S_{t-1}k_t$理解为用当前的键去旧的记忆中检索值$V_{old}$,当遇到$V_{new}$的时候,$V_t$对于同一个$K_t,$不再盲目的覆盖:$$v_t^{\text{new}}=(1-\beta_t)\,v_t^{\text{old}}+\beta_t\,v_t$$
	- $$S_t=S_{t-1}-\underbrace{v_t^{\text{old}} k_t^\top}_{\text{删除}}+\underbrace{v_t^{\text{new}} k_t^\top}_{\text{写入}}$$
	- $v_{new}$就是旧的v和新的v的学习组合,由动态因素$\beta$控制,beta在(0,1)之间,当beta=0的时候旧的v保持不变,当beta=1的时候旧的v完全擦除
	- DeltNet架构图
	- 从总体上看，DeltaNet 遵循 Llama 推广的现代 Transformer 模块设计，交替使用 token 混合（DeltaNet 取代了自注意力机制）和通道混合（SwiGLU）。主要的架构改进集中在 token 混合层，并在此层引入了三项关键改进。==首先，将查询和键处理的原始 L₁ 归一化和 1+ELU 激活函数替换为 L₂ 归一化和 SiLU 激活函数。其次，在查询、键和值的线性投影之后添加了短卷积运算。第三，在最终投影之前加入了输出归一化。==
	- 对于Q和K的归一化
		- 首先回归一个概念:特征值
			- 公式:$$Ax = \lambda x$$
			- 代表x通过矩阵A的变换,在x方向上长度变化多少(λ)
		- 在DeltaNet的公式中:$$S_t = S_{t-1}(I - \beta k_tk_t^T)+v_tk_t^T$$
		- 首先来看矩阵$$A = I-\beta k_tk_t^T$$
		- 对于一个$k_t$方向上的向量:$$Ak_t = k_t - \beta k_tk_t^Tk_t$$
			- 又因为$$k_t^Tk_t = ∥kt​∥_{2}^2​(L_{2}范数的平方)$$
			- 所以$$Ak_t = (I-\beta∥kt​∥_{2}^2​)k_{t}$$
			- 因此我们可以得出,经过矩阵A,$S_{t-1}$在$k_t$这个方向上的变化(特征值λ)为$$(I-\beta∥kt​∥_{2}^2)​$$
		- 对于一个垂直于$k_t$方向上的向量:$$x⊥k_t​,k_{t}^Tx = 0$$
			- $$Ax = (I-\beta k_tk_t^T)x=x - 0=x$$
			- 特征值为1
		- 这就是这个矩阵特殊的地方:不会更改在空间中与k_t正交的向量,只改变在k_t方向上的向量
		- 对于L2归一化
			- 公式:$$\hat{\mathbf{x}}=\frac{\mathbf{x}}{\sqrt{\sum_{i=1}^{n} x_i^2}}$$
			- 并且满足$$\|\hat{\mathbf{x}}\|_2 = 1$$
			- 应用到特征值(k_t方向)中==,λ = 1-β,==其中β在(0,1)之间,所以也把λ控制在(0,1)之间,保证了变化的稳定
			- 当β = 1的时候
				- 原矩阵就变为了$$(I-k_tk_t^T)$$
				- 假设有个向量a
				- 我们可以得到$$a(I-k_tk_t^T)=a-ak_{t}k_{t}^T$$
				- 又因为$$∥k_t​∥_{2}^2=1$$
				- 所以$$ak_t^T就是a在k方向上的投影标量$$
				- 那么$$ak_tk_t^T就是a在k向量上的投影向量$$
				- $$a-ak_tk_t^T就是a减去在k方向上的投影向量$$
				- ==带入$S_{t-1}$就是原来的记忆减去在${k_t}$方向上的向量,但是与$k_t$正交的向量保持不变==
		- 此操作有助于随着时间的推移保持不同键向量之间更清晰的分离, 从而减少上文中讨论的存储模式之间的干扰（或检索错误）
