- 在Softmax Attention中,我们通过显式的去保存**每一个历史的KV**,这意味着当有一个新的Q,**它可以非常轻松的查找到与之相似的K**(历史信息),这种方法可以灵活的适应并从给定的上下文中学习
- 但在线性注意力中,我们并不通过显式的将键值对存储在内存中,那么线性注意力是如何从历史上下文中获得信息的呢?
	- 一种理解方法就是线性注意力学习了==一个从键向量映射到值向量的回归函数==,也就是说,使用键向量K作为输入,通过这个回归函数$f(K)$,我们得到与之对应的输出$V$
	- 从某种意义上来说,线性注意力就是把上下文中的键值压缩到回归函数f中对其进行编码,这可以被视为==神经记忆==
	- 但是我们该如何训练这个函数使得其能更好的反应键值关联呢?
	- 对于$k_j$,我们可以通过f去预测目标值向量$$k_j \rightarrow f_{\theta} \rightarrow \hat{v_{j}} \rightarrow Loss \leftarrow v_{j}  $$通过对目标值向量和预测值向量应用损失函数,因此目标就很明显了,就是最小化损失函数$$L(\theta) \sum_{j=1}^t Loss(f_{\theta}(k_j),v_j)$$
- 如何选择Loss?
	- 一个非常简单理解的方法就是去求负点积:$$Loss(a,b) = -<a,b>$$即使ab之间的点积尽可能的大(相似度尽可能大)
- 因此,我们可以把Loss写为以下形式$$Loss(S) = -(k_tS)^Tv_t$$并通过SGD更新参数:$$S_t = S_{t-1} - \beta_{t} \nabla L_t(S_{t-1}) = S_{t-1} + \beta_{t}k_{t}^Tv_{t}$$这里的β即为学习率
- Surprise! **这里求出来的更新规则与线性注意力的更新规则高度一致**:
	- ==这等价于使用键值对通过随机梯度下降来训练一个线性回归模型==!
- 但是我们能一眼看出,我们的损失函数Loss存在很大的问题,例如,我们可以通过简单的变化K的长度来使得Loss变化,这是我们不想看到的
- 非常简单,更换Loss!
	- 我们使用预测值和真实值之间差向量的L2范数![[线性注意力算法2.jpg|513]]$$Loss(a,b) = \frac{1}{2} \|a-b\|_2^2$$$$Loss_t(S) = \frac{1}{2} \|k_tS - v_{t}\|_2^2$$
	- 类似地,==我们可以通过随机梯度下降来更新权重矩阵S,带入损失函数并计算梯度我们得到以下更新规则==$$S_t = S_{t-1} + \beta_t k_t^T(v_t - k_tS_{t-1})$$这个更新规则被称为delta规则
- 但是新的问题随之而来,我们如何去使用高效大规模训练呢
	- 有了线性注意力的分块算法之后,现在来看看如何对Delta去做同样的事情,首先将Delta规则表示为递推关系:$$S_t = S_{t-1} + \beta_{t} k_{t}^T(v_t - k_{t}S_{t-1})$$$$S_t = (I - \beta_t k_t^Tk_t)S_{t-1} + \beta_t k_t^Tv_t$$简化一下符号:$$S_t = A_tS_{t-1} + B_t;A_t = I - \beta_t k_t^Tk_t;B_t = \beta_t k_t^Tv_t$$
	- 现在我们来展开递推式:$$\begin{aligned} S_1 = B_1\\ S_2 = A_2B_{1} + B_2\\S_3 = A_3A_{2}B_{1}+A_{3}B_{2} + B_3\\S_{4}=A_{4}A_{3}A_{2}B_{1}+A_{4}A_{3}B_{2}+A_{4}B_{3}+B_{4}\end{aligned}$$到目前为止,我们可以看到一个清晰的规律:状态矩阵S_t是矩阵B1,B2到Bt的总和,每个矩阵都乘以相应的矩阵,每个Bt都乘以相应的矩阵,因此我们可以将状态矩阵St表示为Bt的求和$$(1)S_{t} = \sum_{i=1}^{t} (\prod_{j=i+1}^t A_j)B_i$$
	- 但我们真正关心的是分块算法,我们可以类似的使用分块的思想,把T分为两个部分$$i:1,2,3,...C-1,C,C+1,C+2,....t$$第一部分来自第一个分块(1,C),第二部分来自第二个分块的项(C+1,t)$$S_t = \sum_{i=1}^{C} (\prod _{j=i+1}^{t}A_j)B_i + \sum_{i=C+1}^{t}(\prod _{j=i+1}^{t}A_j)B_i$$也可以把累乘分为两个部分$$S_t = \sum_{i=1}^{C} (\prod _{j=i+1}^{c} \prod _{j=C+1}^{t} A_j)B_i + \sum_{i=C+1}^{t}(\prod _{j=i+1}^{t}A_j)B_i$$我们可以去提取一下从C+1到t的累乘(因为不依赖于索引i)$$(2)S_t = \prod _{j=C+1}^{t} A_j \sum_{i=1}^{C} (\prod _{j=i+1}^{c} )B_i + \sum_{i=C+1}^{t}(\prod _{j=i+1}^{t}A_j)B_i$$
	- 现在我们再来对比一下公式(1)和公式(2)的第1部分,发现,他与状态矩阵S_t具有完全相同的形式,唯一不同的就是累加范围:$$(3)\sum_{i=1}^{C} (\prod _{j=i+1}^{c} )B_i;(1)S_{t} = \sum_{i=1}^{t} (\prod_{j=i+1}^t A_j)B_i$$因此,我们可以直接进行一个化简,把(3)当作S_c,也可以是第一个分块结束时的状态矩阵$$(4)S_t = (\prod _{j=C+1}^{t} A_j) S_{[1]} + \sum_{i=C+1}^{t}(\prod _{j=i+1}^{t}A_j)B_i$$
	- 这个公式表明当前的状态矩阵St是由前一个分块结束时的状态矩阵S_[1] 和当前分块所带来的贡献组成
	- 现在我们来整理一下(4)式,把他推广到多块多步:$$(4)S_t^{[r]} = (\prod _{j=tC+1}^{tC+r} A_j )S_{[t]}^{0} + \sum_{i=tC+1}^{tC+r}(\prod _{j=i+1}^{tC+r}A_j)B_i$$将$$S_t^{[r]}$$记为第t个分块中第r步的状态,现在的问题在于将两部分表述为矩阵乘法,以实现硬件高效的训练
- 通常情况下,这里的累乘是无法被写作矩阵的,但==是这里的矩阵具有对角低秩结构,因此我们可以用WY presentation来转换==$$\prod_{i=1}^{t}\left(\mathbf{I} - \beta_i\mathbf{k}_i\mathbf{k}_i^{\top}\right)=\mathbf{I}-\sum_{i=1}^{t}\mathbf{w}_i\mathbf{k}_i^{\top}$$
- $$S_{[t]}^{r} = I - \sum_{i=1}^{r}(k_{[t]}^{i})^Tw_{[t]}^i + \sum_{i=1}^r (k_{[t]}^{i})^Tu_{[t]}^i$$然而其中的W和U仍有递推形式,幸运的是,我们可以通过UT变化来把这些递推改写为矩阵形式
